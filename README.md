# Safe Maps

Safe Maps es una plataforma web de análisis de riesgo urbano basada en ecuaciones diferenciales y análisis geográfico.

## Objetivo

Visualizar cómo evoluciona el riesgo urbano a lo largo de una ruta en Cali, Colombia.

## Tecnologías

### Frontend

- Next.js
- TypeScript
- Tailwind CSS
- MapLibre GL

### Backend

- FastAPI
- Python
- PostgreSQL + PostGIS
