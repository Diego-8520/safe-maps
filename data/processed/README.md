# data/processed — Processed JSON

Clean, transformed JSON files generated by `scripts/prepare-db-seeds.ts`.

These files are the intermediate layer between the raw Excel and the SQL seeds.

## Files

| File | Rows | Description |
|------|------|-------------|
| `communes.json` | 22 | Commune identifiers and names |
| `commune_risk_profiles.json` | 22 | Risk variables in 0–100 scale |
| `annual_crime_indicators.json` | varies | Homicide counts by commune and year |
| `risk_time_windows.json` | varies | Risk levels by time of day |
| `data_sources.json` | 1+ | Data source registry |
| `risk_model_versions.json` | 1 | Euler v1 model descriptor |
| `risk_model_coefficients.json` | 5 | Euler v1 coefficients (C, S, V, I, F) |

## Generate

```bash
# At repo root (requires npm install first)
npm run prepare-seeds
```

## Validate

```bash
npm run validate-seeds
```
